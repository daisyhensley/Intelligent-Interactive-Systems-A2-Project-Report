# Intelligent Headphones System

**Project Overview**
The project constructs an interface in Python using Tkinter designed to represent a context-aware intelligent headphone system. The system responds to differing environmental sounds and gives users greater control over how interruptions are managed. 

**Features**
- Simulated environmental sound detection
- Context-dependent headphone responses
- Differing audio mode controls (Noise cancelling, Ambient, None)
- Notifications explaining system responses
- Detection history and reset controls

**Setup**
- Run from project directory/terminal with python main.py

**Limitations**
- Simulation and headphone responses are purely simulated. No machine learning is actually occurring.
